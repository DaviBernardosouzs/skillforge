# {{title}}

{{description}}

## Quando usar
- O usuário pede um documento deste tipo (ex.: ata, relatório, proposta).
- O usuário passa anotações soltas e quer o documento no formato padrão.

## Entradas
- Assunto e público do documento.
- Anotações, dados ou rascunho do usuário.

## Processo
1. **Reúna as informações** — liste o que falta para cada seção e pergunte ao usuário antes de inventar.
2. **Preencha a estrutura** — siga exatamente o modelo abaixo, sem adicionar nem remover seções.
3. **Revise o tom** — frases curtas, voz ativa, termos que o público entende.

## Formato da saída
Use SEMPRE esta estrutura:

```markdown
# [Título]
## Resumo
## Contexto
## Detalhes
## Próximos passos
```

## Armadilhas
- Inventar números ou datas que o usuário não informou.

## Verificação antes de entregar
- [ ] Todas as seções do modelo estão presentes e nesta ordem.
- [ ] Nenhuma informação foi inventada.
